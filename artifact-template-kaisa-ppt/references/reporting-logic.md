# 工作汇报的逻辑与结构

## 从要解决的业务问题组织报告

默认是可独立阅读、可供会上追问的公司专项报告，按 [专项汇报密度](company-report-density.md) 区分日常经营/决策阅读与年度成果展示。开篇让受众掌握主张、理由和相关投入；正文保留足以核查这些判断的证据。只有用户明确指定演讲或远距离投影用途时，才调整为讲述型承载量，必要业务依据仍需有合适的交付位置。

在私有底稿写清：本次汇报要回答什么、建议是什么、为什么成立、对经营有什么影响、需要受众做什么。涉及真实选择时解释取舍；纯进度汇报不硬造审批事项，也不为完整形式虚构备选方案或报价。

| 任务 | 开篇要回答 | 正文怎样支撑 |
|---|---|---|
| 经营复盘 | 完成多少、与目标差多少、主要判断是什么 | 目标/实际/同期等适用基准 → 贡献和差距 → 原因证据 → 对应措施及后续预测 |
| 活动或营销立项 | 围绕什么销售任务，为什么采取这个方案，投入多少 | 项目与客户问题 → 资源与活动的具体作用 → 内容与客户承接 → 费用结构及交付 → 实施安排 |
| 投资定位 | 项目机会与核心取舍是什么 | 土地/市场/客户/竞争证据 → 产品与价格逻辑 → 成本资金及回报情景 → 推荐方案 |
| 产品方案 | 现方案哪项影响使用或经营，建议怎么改 | 原图和指标 → 问题及影响 → 调整对照 → 空间/成本/运营结果与实施条件 |
| 专项进度 | 目前到哪里、偏差在哪里、下一步需要什么 | 关键节点与实际状态 → 偏差原因 → 对全局影响 → 责任、措施和日期 |

这些是论证顺序，不是必须逐项各占一页的固定目录。一般背景、机构介绍、流程、效果图根据其证明作用穿插；不能让目录替代分析。

## 主张、证据与业务含义要接得上

- 上层结论必须能由下层材料支持。价格、数量、时间、客户行为、空间条件、实际结果等是证据；“提升品牌、增强体验、形成传播”本身不构成证据。
- 同层事项保持同一分类依据。活动范围、客户需求和媒体形式不混成三个并列“优势”；总额与部分金额不混成同口径比较。
- 对指标交代“与谁比、差多少、为什么、会怎样”。只有总数和表格时继续解释构成与业务含义。
- 对建议交代“解决什么问题、采用何种做法、需要哪些资源、预期产生什么作用”。效果预测与实际结果区分，不能把资源数量直接折算成成交承诺。
- 对合作说明“购买/引入的具体资源、交付形式、使用场景、承接动作”。知名品牌、来宾身份及氛围图不能单独证明投入值得。
- 有可比方案时写清选择依据；没有可比报价时不宣称更便宜、更优或投资回报成立。可以利用已知费用分项分析投入结构，不能编造报价、转化率或回款。

证据不足时定向查现有资料；会改变核心判断的缺口才集中询问。缺失目标或客户数据不能用通用话术填补，更不能为了让结论完整而编造。交付聊天说明具体缺口，成品保持真实的建议、计划和测算状态，不追加后台核验章节。

## 每页完成一个充分展开的回答

“一个业务问题”应容纳回答它所需的多个证据单元。不要将“一页一个问题”误写成“一页一个大数或一句结论”。例如“这项费用买到了什么”应同时看到费用构成、资源内容、适用对象和承接方式；不必拆成四页口号。

一页内按材料建立阅读层次：左上主题或具体判断 → 关键证据/比较/图示 → 必要解释 → 业务结论或对应动作。标题已表达结论时，导语只补新的逻辑；无需强制每页都设导语或页底总结。

私有页表至少能回答：

| 本页业务问题 | 本页判断 | 哪些资料/计算支持 | 对本项目意味着什么 | 采用什么图文关系 | 为什么需要独立成页 |
|---|---|---|---|---|---|

这是检查维度，不是要求把空表交给用户。证据与解释应写成可读正文，不能只留关键词。页面未写满不必填充，但不能留下本应回答、资料又已具备的关键问题。

## 对执行细节做层级安排

主席主线突出经营目的、关键依据、方案选择、主要投入与资源、实施影响；完整报告可保留必要的现场、产品和执行细节。纯设备清单或逐分钟操作可集中为执行附件，不把决策依据全部移到附录。

其他领导按职责展开。例如营销领导关注客群与转化安排，设计领导关注图纸、技术条件和成本影响。受众不同改变信息排序与专业深度，事实与计算口径保持一致。

## 低密度整稿的重组

按同一决策把分散的货量、构成、价格和销售影响集中起来。只有合计数字的页、重复展示同一项目图的页和不增加独立判断的过渡页，应考虑合并。不要锁定上一版20页或其他页数，再在每页底部加两句文字。

证据少时缩小页面任务或定向补资料，不用大图、大数字和空泛建议掩盖缺口。证据充分时容纳必要比较与解释，不能为讲述节奏拆成多页提词卡。封面和确有用途的章节页不适用此密度检查。

## 页序检查

1. 只读标题，能否看出问题、判断、理由和安排的推进？只有“背景、目的、流程、预算”等分类时补上真正结论。
2. 连读正文，关键结论能否找到证据？一项建议是否被换词重复，而没有新增事实？
3. 去掉某页，是否损失独立信息或关键关系？没有损失时合并或删除；有信息却承载不足时补全原页。
4. 是否把一项完整论证拆散成多页，以少量文字配同一张图片？按业务问题重新编组。
5. 能否回答受众最可能追问的“为什么、凭什么、投入买到什么、谁来承接”？这项检查由 Agent 自主完成，不增设审批程序。
