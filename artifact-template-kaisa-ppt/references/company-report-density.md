# 阅读型汇报的信息密度

每页集中回答一个问题，留下回答问题所需的事实、构成、对照和解释。若读者需要来回翻三页才能核对同一个指标，把基准、变化及其原因重新放到一起。整页只有一项普通数字和概括性形容词时，应补充材料或合并页面。

| 页面任务 | 适宜同页呈现的证据 |
|---|---|
| 经营差异 | 目标、实际、差额、贡献最大的分项及影响 |
| 服务体验 | 到达或请求量、处理能力、积压时段、主要例外 |
| 成本选择 | 同口径的投入、服务范围、期限、未计入项 |
| 技术或工程 | 当前状况、关键参数、图示位置、调整后的影响 |
| 培训交接 | 实际操作顺序、责任接口和读者会遇到的例外 |

现场演讲、培训演示与长篇阅读材料有不同的观看距离。需要投影时提高字号、拆分确有必要的环节；正式审议时保留比较和数据口径。表格用于查数，图像应能证明位置、差异或动作。

## 从原页辨认密度

- 反例页提出“三单元降低同项目购房总价”。总平图占约半页，只能说明位置。右侧两个横条的数字与面积标签叠在一起，读者难以对应所比较的户型。该页应给同单价下两类户型的面积、例算总价及差额，用表头标清单位。总平图仅在确需定位时保留到可辨认的大小。[低密度反例](visuals/counterexample-low-density.png)
- 原稿第 17 页用原始平面和家具布置图对照，尺寸标注与空间用途可以在图上查到。下方参考图只说明室内风格。遇到需要审尺寸或讨论改造的位置，面积应优先给图纸。样例只供看构图，尺寸和图片须换成本次材料。[图纸与空间示例](visuals/standard-orange-detail-17.png)

终稿逐页试读。指明本页比前一页多交代了什么，以及哪一项比较、条件或参数会影响读者的判断。一个结论在标题、导语和页底出现三次时，保留最清楚的一处。删除图片后论证依旧完整、多个小标题下找不到不同事实，退回重组或合并。图表里找不到判断所依据的数据，先补材料或收窄结论，再做美化。
