# 阅读型汇报的信息密度

每页集中回答一个问题，留下回答问题所需的事实、构成、对照和解释。若读者需要来回翻三页才能核对同一个指标，把基准、变化及其原因重新放到一起。整页只有一项普通数字和概括性形容词时，应补充材料或合并页面。

| 页面任务 | 适宜同页呈现的证据 |
|---|---|
| 经营差异 | 目标、实际、差额、贡献最大的分项及影响 |
| 服务体验 | 到达或请求量、处理能力、积压时段、主要例外 |
| 成本选择 | 同口径的投入、服务范围、期限、未计入项 |
| 技术或工程 | 当前状况、关键参数、图示位置、调整后的影响 |
| 培训交接 | 实际操作顺序、责任接口和读者会遇到的例外 |

现场演讲、培训演示与长篇阅读材料有不同的观看距离。需要投影时提高字号、拆分确有必要的环节；正式审议时保留比较和数据口径。表格用于查数，图像应能证明位置、差异或动作。
