# 模板、汇报对象与一页纸

## 三套 PPT 模板

| 选项 | 原生参考 | 封面预览 | 使用方式 |
|---|---|---|---|
| 橙色越海版 | `assets/reference.pptx` | `assets/preview.png` | 默认；橙色品牌识别，白底阅读区，黑色正文，页首概括、重点与结论统一越海橙，少量深蓝辅助 |
| 原汇报橙黄版（雲玺样本） | `assets/reference-yellow-report.pptx` | `assets/preview-yellow-report.png` | 用户指定原稿或截图对应时使用；继承封面、页眉、横线与标识 |
| 红色封面版 | `assets/reference-red-cover.pptx` | `assets/preview-red-cover.png` | 红色品牌封面，内页白底、暖灰和克制红色强调 |

每次只选一套主模板，颜色与职位不绑定。原稿保持不变，在工作副本中改编。历史项目名、年份、数据、图像、页脚和备注必须替换。

红色封面版可沿用样本红色背景、橙金曲线和正式标识；内页建议强调色 `#C00000`、浅红 `#FCEEEE`。长段正文保持黑色，不铺满红色块。

## 先确定主读者，再确定结构

受众影响信息排序、证据深度、行动表达和披露范围。各版本的事实、时间和计算口径保持一致。

### 1. 主席或最终决策者

**核心关切**：经营结果、现金与回款、重大偏差、方向选择、资源投入、关键风险、需要拍板的事项。

**推荐主线**：结果与核心判断 → 关键差距或机会 → 支撑依据 → 方案取舍 → 经营影响 → 推荐动作 → 决策事项。

**页面要求**：

- 首页之后尽快给出一页决策摘要，写清结果、建议、影响和需决定事项。
- 关键数字与目标、预算、同期或方案比较相连，避免只有总数。
- 有真实选择时明确推荐，写清选择理由、代价和实施条件。
- 主要测算、货盘明细和执行清单可进附件，支撑结论的关键依据保留在主线。
- 没有审批事项时，以结果和下一步收束，不硬造“请示批准”。

### 2. 集团、区域或项目经营管理层

**核心关切**：目标达成、销售与回款、库存、成本、利润、供货和工程节点、跨部门责任。

**推荐主线**：目标与实际 → 差距构成 → 原因证据 → 后续预测 → 改进动作 → 资源与责任 → 会议决议。

**页面要求**：

- 每个重点偏差回答差多少、由什么构成、哪些因素可控、对后续目标有何影响。
- 动作与问题逐项对应，明确责任部门、完成物、日期和所需协同。
- 经营表保留目标、实际、差额、完成率和必要同期，不用只有完成值的指标卡替代分析。
- 问题尚未有定论时给出当前判断和所需业务决定，不把查数任务写成会议决议。

### 3. 营销、设计、工程、财务、投资等专业条线

**核心关切**：本专业的判断依据、方案细节、接口条件、成本与进度、交付标准。

**推荐主线**：专业问题 → 事实与测算 → 方案 → 业务影响 → 执行与接口 → 需要协同或审议的事项。

营销汇报重点看货盘、客户、价格、渠道、转化、费用、签约与回款；设计汇报重点看图纸、空间、技术指标、成本和运营；工程汇报重点看节点、工作面、质量、安全和交叉依赖；财务与投资汇报重点看资金、成本、收益、测算条件和合同权利义务。

### 4. 政府机构

**核心关切**：合规、交付与民生、公共安全、属地责任、计划可执行性、风险外溢和需要协调的事项。

**推荐主线**：项目与事项事实 → 已完成工作及履约 → 当前困难与影响 → 后续安排 → 请求协调或支持事项。

**表达要求**：使用正式、准确、可核验的事实语言。请求写清具体事项、涉及范围、希望完成时间和项目方配套责任。删除内部经营底线、客户隐私、未经确认的归因和内部争议。

### 5. 金融机构、投资者或债权人

**核心关切**：现金、资产与负债、偿债或回款安排、担保与增信、项目进度、信息披露的一致性和可追踪性。

**推荐主线**：关键财务与项目事实 → 资产/现金/进度变化 → 资金安排 → 履约计划 → 风险处置与请求事项。

实际、预测和测算情景分开；融资、到账、抵押、担保和批准状态不得凭经验补写。

### 6. 合作方、供应商或外部业务伙伴

**核心关切**：合作范围、权利义务、投入与交付、时间、接口、费用和双方责任。

**推荐主线**：共同目标 → 已确认事实 → 方案与分工 → 投入及交付 → 节点 → 需确认或协调事项。

不使用对内管理口吻，不向无关合作方披露项目经营底线和其他客户信息。

## 混合受众与使用场景

主席与职能负责人同时参会时，以主席决策主线组织主稿，将专业细节置于对应章节或附件。政府与合作方共同参会时，只使用各方均可知悉的共同事实，个别诉求另做专项材料。

阅读型报告与投影型报告分别排版。主席汇报不自动等于低密度演讲稿；年度经营审议也不因“年度”二字改成成果展示。需要远距离投影时放大字号、拆页或增加附件，不缩小字体保留全部文字。

## 一页纸与决策摘要

主席或最终决策者汇报默认同时交付独立一页纸，除非用户明确不需要；其他汇报根据任务需要配置，不机械增加确认。

主席主稿前部应有决策摘要页，这与独立 A4 一页纸不同。独立一页纸用于离开 PPT 单独传阅，默认采用 [通用 Word 母版](../assets/one-page-report.docx)，具体见 [一页纸写作与排版](one-page.md)。默认交付可编辑 Word；当前环境支持可靠单页 PDF 输出时再附 PDF，不以未经验证的转换补交。

配套决策一页纸可提炼核心结果、建议、关键依据和确需决定的事项。个人说明、通知、技术复盘等独立一页纸直接按实际读者和用途写，章节及顺序由本次材料决定。
