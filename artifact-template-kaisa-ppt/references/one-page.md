# 一页纸：目的、安排、费用

## 成品标准

标题和结构一针见血，读者迅速看清**目的是什么、怎么做、花多少钱**。内容从本次PPT提炼，不新增事实、建议或结果，不逐页摘抄，不写成缩短后的长报告。

方案、活动、立项类材料默认采用“具体事项标题＋目的＋安排＋费用”。5W用于检查信息完整，不机械排成五个英文栏目。经营复盘等无预算事项的任务，按实际问题使用“结果、原因、措施”等直接标题，不虚构费用申请。

## 默认结构

| 部分 | 写什么 | 写法 |
|---|---|---|
| 标题 | 项目＋具体事项；确有预算申请时写明费用申请 | 如“信悦湾佳士得活动方案及费用申请”。不用“赋能发展”“价值升级”等口号，不用抽象判断充当标题 |
| 一、目的 | 这件事要解决什么业务问题或达到什么目标 | 通常一两句，直接写新品销售、客户到访、成本改善等具体任务。不要写一段宏观背景或重复活动流程 |
| 二、安排 | 做什么、谁负责/参加、何时、何地、主要做法 | 按实际事项简短分列；多个活动各说明地点、对象及核心内容。把决定规模与安排的参数留下，不铺逐分钟流程 |
| 三、费用 | 总额、主要分项、税口径及列支项目 | 审批总额准确列示，分项与总额一致。只写有助于看清用途的重点，不转写整张费用表 |
| 收尾（需要时） | 本次真正需要批准的事项 | 如“提请同意上述活动及预算”。不再重复一遍目的、效果和全文结论 |

时间未定就写“日期待定”，不写“结合有关安排进一步落实”。责任部门或地点只采用已知内容，不为补齐5W编造姓名、日期、场馆和职责。

## 5W核对及做法、费用

- **Why**：目的是否具体？“提升品牌影响力”若没有明确对象和业务任务，不足以单独作为目的。
- **What**：到底办什么、改什么、交付什么？名称和范围是否准确？
- **Who**：谁主办、谁参与、谁负责实施？主办、特邀、供应方不能混用。
- **When**：什么时候做？已知日期准确写明，未定照实写。
- **Where**：在哪里做？地点表达足以判断事项，不能把图片场景当真实地址。
- **How与费用**：主要怎么做、投入多少？5W未直接包含做法和金额，仍须按用户要求交代。

以上为Agent在底稿中的检查，不把检查表或缺项核验清单塞进一页纸。

## 信息取舍

优先保留目的、活动/方案内容、主要参与方、关键规模、日期地点和金额。理由只保留解释当前选择所必需的事实，放在相关句子中，不另起一段空泛“价值与意义”。

机构沿革、宏观形势、完整设备清单、一般接待细项及口号通常留在PPT或执行资料。一页纸不按原章节占比压缩，也不为了凑满一页增加文字。

费用结构或占比只有在帮助判断时才保留，不能因为算出了数字就强行加入。数字保持含税/未税、单位、期间一致。计划人数不写成实际到访人数，建议不写成已批准安排，预计效果不写成成果。

如果PPT本身缺少目的或关键事实，整份报告任务中补足正文再同步提炼；仅做摘要时不擅改原稿，在聊天中说明具体缺口，不编造理由。

## 直接写动作

用“邀请谁、在哪举办、介绍什么、安排什么、申请多少”等具体表达。一页纸不用“围绕着……”“聚焦……”“以……为抓手”“承接……”“形成……闭环”等概括性套语代替事实和动作；不能只换近义词保留原句。

- “围绕新品展示，承接高净值客户深度交流” → “邀请意向客户参观新品样板房，活动后安排复访和房源洽谈。”
- “将合作资源落实为可使用内容，促进持续触达” → “安排专家讲座，发布活动图文和视频，并由销售人员逐组联系客户。”
- “强化资源协同，形成客户经营闭环” → 按原PPT写出实际责任人或部门、客户动作和时间；缺少实际安排时删去这句话。

示例只说明写法，不向其他任务添加未获授权的工作安排。正文删去一句后，若目的、安排、金额等信息完全不受影响，通常可以删除。

## 验收与排版

1. 标题是否直接点明事项？各级标题是否能用“目的、安排、费用”等熟悉词语表达？
2. 读者能否立即回答“为什么做、做什么、谁负责/参加、何时何地、怎么做、花多少钱”？
3. 是否仍有只表达态度、效果或抽象关系、没有具体动作的句子？删除或改写，尤其检查“围绕、聚焦、承接、赋能、闭环”。
4. 每段回到PPT核对范围、人物角色、人数、日期地点及费用，未引入额外事实或强化结论。
5. 实际渲染一页、清楚可读；默认A4竖向，正文约11—12 pt起排。允许必要留白，不靠凑字填满纸面。Word与PDF一致。

既有失败复盘见 [调研与佳士得案例校准](research-and-retrospective.md)。其中v1.5的示范段落也曾过于概括，现以本文件的直接结构和写法为准。
