# 佳兆业汇报材料一页纸

以配套的[可编辑 Word 母版](../assets/one-page-report.docx)为起稿文件。在副本内替换文字、增减条目，保留原段落格式与自动编号。母版取自用户指定的 2 月 24 日晨会材料，已将示例中的人员及经营数据换成占位文字。单做一页纸时直接使用本次定稿材料或用户提供的事实；配套 PPT 时与定稿保持一致。

## 页式与字体

| 位置 | 母版设置 |
|---|---|
| 页面 | A4 竖向，白底黑字，单栏。左右页边距各 2.10 厘米，上下各 2.30 厘米。 |
| 第 1 行 | “〔项目名称〕项目工作汇报（X月X日）”。专项材料可将“工作汇报”换为具体事项。居中，宋体四号（14 磅），加粗。 |
| 第 2 行 | “汇报人：〔姓名〕 提供主体：〔部门或工作组〕”。同一行居中，宋体四号（14 磅），加粗。其下留一空行。 |
| 一级标题 | “一、销售动态：”等，宋体小四（12 磅），加粗。使用中文数字及顿号。 |
| 分项 | “（1）整体销售情况：”等，全角括号内用阿拉伯数字，每一大项从（1）起。宋体小四（12 磅），常规字重。 |
| 事实与行动 | 宋体小四（12 磅），常规字重。逐条以“·”紧接正文，竞品简述可在名称后接一段，用下段续写最新动态。 |

标题、署名和正文均为 **1.5 倍行距**。正文及小标题沿左版心起排，沿用母版的两端对齐及零段前段后设置，续行回到左版心。中文、数字和西文使用母版指定的宋体。使用原生文字，不套用 PPT 页眉、品牌色、卡片或彩色重点。粘贴新内容时仅粘贴文字。需要更多条目时复制同层级段落，保留字号、字重、行距及编号；不要用空格模拟编号对齐。

## 正文如何组织

晨会、例会及项目经营工作汇报沿用三个一级标题，顺序如下。

1. **一、销售动态：** 按原样分别写整体销售、本期销售、客户维系活动和团队情况。整体销售将累计认购、签约各列一条，写清套数、面积、金额及均价。本期销售注明统计区间或截至日，区分到访、新增认购和累计业绩。活动写清对象与实际进展，团队写已到岗人数、工作安排或节点。“春节期间”“团队复工”等随本期实际更换，无相关事项可删去分项。
2. **二、市场动态：** 每个竞品或市场事项单设分项，先点名对象，交代可比的区位或产品，再写近期的价格、开放、取证、推售等动作和发生日期。区分市场吹风价、备案价及实际成交价。
3. **三、下阶段重点方向：** 用“·”逐条写下一阶段要推进的工作。点明对象和动作，已确定的责任主体、时间或目标随条写入；计划与实际结果分开。

活动方案、费用申请等专项也使用同一个 Word 母版，保留两行页首、宋体字号、编号和条目层级，一级标题按本次议题命名。费用申请可以用“一、活动目的：”“二、活动安排：”“三、费用申请：”，写明对象、时间地点、主要安排、预算总额、重要分项、税费口径及本次提请事项。只有经营周报等适用情形才沿用全部销售栏目。5W 是核实安排的写作提示，不列成页面栏目。

## 交付前

- 用当前材料核对报告日期、汇报人和提供主体。未确认的姓名、单位或数字不得从样稿带入；正式稿清除占位符。涉及缺项时在交付说明中点明。
- 逐条核对本期与累计、认购与签约、含税与未税、金额与单价。保留足以理解判断的事实，删掉重复背景、执行细目和没有具体动作的套话。
- 在 Word、WPS 或可用渲染工具中打开实际页面，核对中文字符、字号、编号、两行页首、正文末条和页数。导出 PDF 时检查打印版确为 A4 一页。超页时合并同类事实或精简次要内容，保持母版字号、行距和页边距。默认交付可编辑 Word 及单页 PDF，用户指定格式时按要求交付。
