# 页面构图与阅读顺序

公司标准分析页从标题进入结论，读者随后查看依据与主体图表。沿用原稿的版心、标识、标题位置和内边距。在同一份材料中，对同类信息维持一致的对齐和字号，允许不同问题采用不同构图。

| 页型 | 主体证据 | 如何放置文字 |
|---|---|---|
| 趋势与异常 | 同一时间轴的需求、产出、队列或费用 | 图上写单位，侧栏解释最大变化及其经营含义 |
| 构成与原因 | 分类对比、贡献分解、观察样本 | 标明分母和期间，把推断与观察分开 |
| 方案比较 | 同一维度比较成本、能力、期限和条件 | 推荐依据贴近影响选择的字段 |
| 动线与操作 | 平面图、业务流程、设备或岗位位置 | 每个标记对应一个动作，注明是否示意 |
| 执行与复核 | 日期、负责人、任务、交付标准 | 同一节点只写一次，交接双方清楚可辨 |
| 照片与图纸 | 现场证据、产品、构造或空间关系 | 比较尽量同尺度，保留图例、尺寸和必要标注 |

需要精确复用版式时可看[原稿几何位置](measured-layout.json)，其数值基于 1280×720 的等效画布。该记录仅保留位置和组件类型，不提供业务文案。

## 图像制作与裁切

排版前就确定每张图要回答的问题、视角和最终落位。需要呈现场地、产品或活动体验且没有适用素材时，直接生成效果图。用全景说明空间与动线，用中景说明人员与设施的关系，用近景说明动作或材料。逐张检查手势、设备、方向、人数和空间关系；图像不能证明的尺寸、价格或业绩，使用单独的图纸或数据说明。图注标明效果图属性。正式成品不留图片占位。

## 在原稿内借鉴审美

公司原稿决定页面构图。封面保留其背景、题名位置和版心，选定的内容页保留其栏数、标题层级、导语位置、信息区与图框。配图数量或比例不合适时，改选公司原稿中合适的页型。

借鉴 Guizang 的图像取舍、景别搭配和成组图片裁切。借鉴 PPT Master 对画面焦点、业务含义、图注清晰度和对象可编辑性的检查。既有图框内可调整裁切，既有文字区可提炼重复。外部工具的杂志封面、瑞士网格、额外装饰带、独立页脚及卡片系统均不作为公司页型。标准橙色原稿的封面沿用整幅底图和原题名位置；业务效果图放在内页原有图片区。
