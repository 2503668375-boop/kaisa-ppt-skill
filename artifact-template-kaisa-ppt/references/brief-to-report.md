# 从议题到完整汇报

## 排版前确定的四件事

在工作底稿用几句话答清前三问，再写出第四问的页序或段序。已有资料能回答的直接采用，只有影响结论、内容分配或交付的缺口才向用户核实。

1. **给谁汇报？** 区分汇报人与主读者，题名页署实际汇报人。说清主读者负责什么、已知什么、在哪里读这份材料。多人参会时，确定谁需要据此作决定或采取行动。
2. **为什么汇报？** 写清本次触发事项，以及读者看完要知道、决定、协调或执行哪件事。纯通报交代清楚影响和当前状态即可。
3. **报什么？** 先试写读者最关心的答案。列出足以支持它的事实、比较和条件，分清资料已经证明的事项与尚待核实的判断。细项是否进入正文，取决于它会不会改变读者的决定或操作。
4. **怎么报，各页怎么分？** 一页纸先定段序，为每段写一句要点。PPT 先排完整页序，每张业务页在底稿写下本页回答什么、用哪项新增证据或具体安排、准备怎样展示。需要配套时，从同一份核心摘要拆页，用图表、图纸或实施细节展开每个判断。仅需 PPT 时无需另交 Word；会议需要的决策摘要可放在 PPT 前部。

逐页连着讲一遍。若删除某页仍能核对同样的依据、做出同样的选择或完成同样的操作，将它并入相邻页。专业判断尚无支撑，先补资料或缩小判断范围。能说明读者为何需要每一页，再打开母版排版。封面、章节和固定结束页按各自用途处理。

以服务试点为例，如果负责人要判断一个新服务值不值得占用原时段，就要比较正常业务贡献、试点可能取得的净贡献及付费意愿。已有执行经验能说明有条件试办，实际订单才能说明有人愿意买。若暂缺实绩，就写清要测什么、用什么对照、由谁拿结果。换成给当班同事的操作说明，则优先说明分工、动线、时间和例外处理。

| 任务 | 核心材料 | 读者看完应能做什么 |
|---|---|---|
| 情况通报 | 已发生事项、范围、影响、当前状态 | 理解变化及与自己的关系 |
| 经营或服务复盘 | 可比时段、目标与实际、变化构成、原因证据 | 判断差距来自哪里 |
| 方案审议 | 可行选项、投入、作用机制、尚未确定的条件 | 比较取舍并作出有依据的选择 |
| 工作交接或培训 | 操作顺序、现场图示、常见例外、联系人 | 按要求完成下一项工作 |
| 对外协调 | 已履责任、具体影响、对方需要协助的事项 | 确认分工和时间 |

按业务核对材料。数量分清期末存量和期间增量，金额分清预算、承诺和实际支付。数字比较先对齐单位、统计期、范围和分母。图纸比较核对版次、比例及变更位置，案例核对适用条件。条件不同又无法校正时分别陈述，说明哪些结论仍然成立。
