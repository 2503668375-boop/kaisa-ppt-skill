# 页面构图与阅读顺序

先对照逐页方案，确定读者会在本页找什么答案。普通分析页从左上标题进入，标题下写一句有对象的概括，中段按具体理由、差额来源或安排分段，底部给图、表或图纸。每一段应能指向可核对的列、位置、动作或事实。沿用原稿的版心、标识、标题位置和内边距。同类信息保持一致的对齐与字号。

| 页型 | 主体证据 | 如何放置文字 |
|---|---|---|
| 趋势与异常 | 同一时间轴的需求、产出、队列或费用 | 图上写单位，侧栏解释最大变化及其经营含义 |
| 构成与原因 | 分类对比、贡献分解、观察样本 | 标明分母和期间，把推断与观察分开 |
| 方案比较 | 同一维度比较成本、能力、期限和条件 | 推荐依据贴近影响选择的字段 |
| 动线与操作 | 平面图、业务流程、设备或岗位位置 | 每个标记对应一个动作，注明是否示意 |
| 执行与复核 | 日期、负责人、任务、交付标准 | 同一节点只写一次，交接双方清楚可辨 |
| 照片与图纸 | 现场证据、产品、构造或空间关系 | 比较尽量同尺度，保留图例、尺寸和必要标注 |

宽表需要横向查数、图纸需要辨认标尺、时间轴需要跨期跟踪时，可把中部依据与下部图表合成主体区，并将判断标在相应数据行、图纸部位或节点上。例外理由写在工作底稿。例如产品审议看原稿第 17 页，上方并排原始平面与布置图，下方以室内参考图交代风格。审新稿时应能读清尺寸，分辨实景、参考案例和本项目方案。[原稿第 17 页](visuals/standard-orange-detail-17.png)

需要研究原稿图文比例时可查[原稿几何位置](measured-layout.json)，其数值基于 1280×720 的等效画布。

## 图像制作与裁切

先确定图要显示的部位、差异或动作，再选图和裁切。优先用能看清该细节的现场实图或正式图纸。只有读者确实需要预览拟议的空间、产品或动作时，才选用标明“方案效果图（AI生成）”的示意。全景交代动线，中景说明人员与设施的位置关系，近景说明动作或材料。逐图核对图注指向的细节在成品上清晰可见。

付费需求、报价差异或预计回款等问题优先用订单、报价、测算或待验证字段呈现。缺少实绩时明确哪些是假设、准备取得什么记录。活动照片可以展示玩法，无法说明付了多少钱、有多少人复购。图片删去也不影响回答本页问题时，把空间让给说明该问题的事实。
