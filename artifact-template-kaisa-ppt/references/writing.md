# 佳兆业汇报的文字表达

## 写成业务负责人会讲、会议纪要能用的中文

公司汇报直接陈述本次需要交代的结果、原因、投入、责任或动作。读者应能认出句子指的是哪笔款、哪项服务、哪个方案或哪一方的责任。上下文已清楚的主语无需句句重写。

看到“加强、优化、赋能、提升、打造、闭环、抓手、协同、价值释放”等词，先删掉修饰，检查余下内容。删整句也不影响读者的判断或操作，就删整句。换一个项目名仍然适用的业务判断，要么补上本次的事实、差异或明确动作，要么删去；公司正式制度和专业术语按原义保留。

专业感来自准确的对象、口径、因果和取舍。采用本业务实际使用的术语，例如周转时长、缺陷率、工单积压、合同履行或回款，不用术语替代论证。

## 标题、导语、正文、图注分工

- **左上标题**提炼成四字、六字或八字业务短语，如“客户邀约”“深圳开放安排”“香港预展客户专场”。同组题名采用相近句法，让读者看得出比较的是哪些事项。把“怎么做、怎样比较、花在哪里”等提问留在底稿；不要用“相关情况”“工作举措”凑字。封面正式题名及必要专名完整保留。
- **标题下的概论**按公文提要的方式提炼。安排页写清对象和怎么分，结果页写结果与关键差异，已有方案直接写结果、方向或安排。确需选择时，写当前建议及影响选择的条件。通常一句即可，须有下文分项或图表支撑。保持短标题与自然中文，不用邀约话术、流程口播、栏目预告或笼统的“综合评估”代替本页结论。
- **中段依据**按事实、差异或条件分段，写出判断从何而来。每段有新增信息，段数随材料确定。
- **下部图表与图注**供读者核对或理解上文。表头和标注写清对象、单位、时点及必要的资料属性。大表、图纸等专页可就近加注。
- **页底结论**：仅在能归纳取舍、经营影响或行动时使用，不设为每页固定组件。

标题、导语、正文和页底不得把同一结论换词说四遍。

## 结果、原因和动作要写实

### 经营结果

写清指标、实际值、比较基准、差额、统计期和构成。只有“完成情况良好、基本达成、稳步推进”而没有数字或具名结果时，重写。

推荐关系：`实际结果 → 与目标/同期/预算相比 → 差额由什么构成 → 对后续经营的影响`。

### 偏差原因

原因必须对应证据。客户反馈、到访、转化、货盘、价格、渠道、放款和工程节点可形成解释；“市场不好、客户观望、团队不足”只有态度，没有完成归因。

内部归因区分可控与外部因素，最终落到可采取的动作。外部汇报只写已确认事实，不把内部推测写成责任结论。

### 方案与取舍

写清推荐什么、为什么选、放弃什么、投入多少、改变哪项经营结果。涉及定位时回答服务谁、跟谁比较、凭什么被选择、产品和价格如何承接；证据不足时不硬造概念。

法定义务、出让条件强制配建和所有竞品都能享有的公共资源，不包装成项目独有客户价值。

### 执行动作

动作包含责任主体、业务对象、完成物和日期。已有明确责任与时点时直接写出；未知时不得编造。

将“持续提升客户转化”改为可检查的安排，例如按真实资料写“案场在某日前完成某批客户复访，记录户型、总价和付款条件反馈，形成下一轮跟进名单”。没有真实客户批次和日期时缩小表述，不留虚假细节。

## 不同对象的措辞

| 场景 | 语言重点 | 避免 |
|---|---|---|
| 主席 | 结果、经营影响、方案取舍、需拍板事项 | 过程铺陈、多个方向平铺、只有执行没有判断 |
| 内部经营会 | 差距、构成、原因、预测、责任和节点 | 只有任务口号、把查数工作写成经营动作 |
| 专业条线 | 技术或营销依据、方案细节、接口和完成标准 | 用宏观价值替代专业问题 |
| 政府机构 | 合规、履约、公共影响、项目责任、具体支持事项 | 宣传口号、内部经营底线、未经确认的归责 |
| 金融机构 | 现金、资产、偿债、回款、进度、实际与预测 | 无依据承诺、混淆到账与计划 |
| 合作方 | 合作范围、交付、费用、节点、双方责任 | 对内命令口吻、披露无关经营信息 |

## 删除 AI 腔与文档自述

### 元话语

删除“本文将、以下是、我们可以看到、综上所述、值得注意的是、本页主要说明、后续页面将展示”。页面直接进入项目、事实和判断。

“现场、解释、后果、证据、策略、结论”等写作标签只留在私有底稿，页面使用具体业务名称，如“11 月签约差额”“高区大户型成交情况”“样板房开放安排”。

### 机械句式

禁用“不是……而是……”式翻转。减少连续三段式、四句排比、机械对仗和每页固定“现状—问题—策略—效果”。实际并列集合可以保留，数量由内容决定。

遇到“先……再……”，检查两项工作是否真有先后依赖。两个客群、两种职责或两项条件被串成流程时，分别写清对象和动作。两批接待、款项到账后办理手续等真实顺序可以保留。

“边界”不单独作为抽象判断，直接写用地红线、供货范围、售价、成本或合同条件；“用地边界”等技术术语可正常使用。

### 空泛收尾

章节末不突然上升到时代、未来、长期主义和宏大价值。收束到项目决定、经营影响、责任人、时间节点或所需支持。

### 无主语和伪精确

少用“得到提升、得以实现、被赋予、有望进一步”等隐藏责任或证据的表达。没有测算依据时不写“显著提升、大幅增长、精准触达、有效控制”。

## 事实、估算与建议的表述

| 类型 | 正文写法 | 必要信息 |
|---|---|---|
| 实际结果 | “截至某日，完成……” | 统计期、对象、单位、口径 |
| 目标/计划 | “年度计划……”“某会议确定……” | 版本、日期、适用范围 |
| 预测 | “按当前……预计……” | 关键假设与影响 |
| 测算情景 | “按均价……测算，货值……” | 输入、公式、单位，不能写成实际 |
| 专业判断 | “基于……建议……” | 证据链与项目影响 |
| 资料缺口 | 改变判断的条件在对应结论旁说明，其余核验记录留底稿 | 同一未定事项仅在影响决定处说明一次 |

内部经营汇报直接陈述核实后的结果。表头例如写“开盘去化”，不附“周报调研”；正文直接写成交约数，页底和附页不另列机构、周报及页码。日期写业务发生日或统计期间，保留“约”“拟”“计划”等原有含义。原始出处、采用口径和计算过程记在私有底稿。独立研究、对外披露或明确要求列出处的文件，按该次交付要求署引。

不能为了语气肯定而删除有事实意义的“预计、测算、计划、约、条件”。不能虚构已核实、已批准、已到账、已签约或已完成。

## 数字、单位和标点

- 金额统一使用元、万元或亿元，同一页避免混用；跨页换算保持一致。
- 百分比变化与百分点变化分开。费率由 1.3% 到 1.0% 写“下降 0.3 个百分点”。
- 人数、金额、业务量、时长及比例写明统计对象与日期；合计与分项复核。
- 按本次业务区分订单与收入、到达与处理、预算与实际等容易混淆的指标。
- 日期统一为 `2026.11.04` 或 `2026 年 11 月 4 日`，同稿选择一种；月份轴可用 `11 月`。
- 中文句内使用中文标点，数字与单位按版式保持不拆行；图表单位尽量放入标题或列名。

## 改写示例

以下均为虚构示例，只示范如何按已有事实改写。

### 1. 空泛营销口号

原句：整合高端圈层资源，以精准触达推动品牌势能转化，形成营销闭环。

题设只有：样板房下月开放，案场已登记意向客户所需面积。

改写：样板房下月开放。建议案场按已登记的面积需求分批邀约客户看房。

### 2. 经营结果口号

同一份十月经营月报只给出营销费率，实际 1.0%，预算 1.3%，未提供同期值、费用总额或差异原因。

应退回的写法：“十月营销费率 1.0%，充分体现费用管控成效，经营效能持续提升。”一个实际值无法证明管控成效或变化趋势。

可交付的写法：“十月营销费率为 1.0%，较预算的 1.3% 低 0.3 个百分点。”若只是月报中的一项指标，放回经营表相应行即可；没有独立分析时，无须扩成一页。

### 3. 已有方案的页首概论

- **竞品开盘。** 两盘同期推售、与本项目争取相近客群，分别去化约六成和不足五成。若项目判断表现不及预期，页首可以写“两个竞品开盘去化不及预期，改善客群争夺加剧。三单元须在开盘前主动邀客，通过开放日增加有效到访。”销售套数、价格及日期放进比较表。只写两组去化数字再接一句“加强推广”，读者还看不出活动为何必要。
- **样板房参观。** 包装参观价值，先问客户离场时应能作什么判断。例如“让改善家庭实地判断三房能否满足居住需求，结合入户空间、阳台朝向和通风差异选定意向户型。”有平面和实物支撑，才写对应体验。无需虚构四房样板、可变户型、面积优势或成交承诺。
- **客户邀约。** 下文分述邀约渠道和到访统计。概论可写“本次重点争取新客首访和意向客户复访，两类到访按家庭分别统计。”顾问如何带看、客户看哪一层，留给接待安排。
- **香港预展客户专场。** 原案已将香港场列为第二项活动，可写“拟邀请业主及重点客户参加香港秋拍预展，安排专家导览和客户交流。”分项交代对象、行程及接待。日期未定只在排期处注明。不能从分项报价或待定日期推出“暂缓”“另定是否举办”或新增客户门槛。

### 4. 外部专项

泛化表述：项目推进面临诸多挑战，恳请给予大力支持。

有效写法字段：项目已完成的具体事项、当前待协调问题及其影响、项目方后续安排、请求对方在某日期前协调的具体事项。

正文只写已核实事实，诉求与项目方责任同页对应。

## 全稿编辑顺序

1. 对照任务简报，删除与议题由来、目的和会后结果无关的内容。
2. 逐页圈出具名对象、事实、动作和条件；只剩形容词与抽象名词的段落重写。
3. 连读短标题查议题是否重复，再通读页首概论，检查判断和依据是否接得上。
4. 检查每个关键数字的时间、单位、口径和比较基准。
5. 拆除无功能的机械对称、口号排比和重复结论。
6. 用本次真实读者的视角朗读；需要旁人“翻译”的句子重写。
7. 最后核对事实，防止润色把计划写成结果、把建议写成批准、把估算写成承诺。
