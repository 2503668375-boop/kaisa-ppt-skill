# 改稿时保留已确认的信息

用户指出模板不符时，核对封面、标识、页眉与内页网格，回到指定原稿副本。若问题是分析不足，检查判断缺哪项比较或证据。若问题是展现太密，先处理重复、对齐和图表选择，保留影响判断的依据。

改写前记录已确认的结论、数字、条件、交付形式与修改意见。完成后对照旧稿，确认关键事实、责任、期限与计算口径保持一致。局部修订无需重做整份材料。

批注按页面名称、所选文字和区域共同定位。用户要求删除一个内容块时，连同该块的底色、边框与装饰移除；不能只删被选中的装饰对象，也不能扩大为删除整页。删掉空泛说明后，只补有依据且与本页问题相关的信息，不为了填满版面再造总结。

用户纠正房型、金额或时间条件时，回查相关正文、图表和计划；使用已确认的行业术语，保留适用范围和例外。最新业务排期可与原案仍适用的创意重新对应，但不能把另一活动的流程挪来填空。

保留修订前版本，另存成品并回读。检查修改页及受影响内容，保持其他页面和公司模板稳定。交付说明本次实际修改与验收范围，不把工作底稿和核查过程塞回正式页面。
