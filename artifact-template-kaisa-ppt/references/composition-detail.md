# 页面构图与阅读顺序

先对照逐页方案，确定读者会在本页找什么答案。普通分析页从左上标题进入，标题下写一句有对象的概括，其下用实际材料展开。多个理由可分段；对应单个数值、部位或动作的依据可就近标注。沿用原稿的版心、标识、标题位置和内边距。同类信息保持一致的对齐与字号。

| 页型 | 主体证据 | 如何放置文字 |
|---|---|---|
| 趋势与异常 | 同一时间轴的需求、产出、队列或费用 | 图上写单位，解释贴近最大变化的时段或数据点 |
| 构成与原因 | 分类对比、贡献分解、观察样本 | 标明分母和期间，把推断与观察分开 |
| 方案比较 | 同一维度比较成本、能力、期限和条件 | 推荐依据贴近影响选择的字段 |
| 动线与操作 | 平面图、业务流程、设备或岗位位置 | 每个标记对应一个动作，注明是否示意 |
| 执行与复核 | 日期、负责人、任务、交付标准 | 同一节点只写一次，交接双方清楚可辨 |
| 照片与图纸 | 现场证据、产品、构造或空间关系 | 比较尽量同尺度，保留图例、尺寸和必要标注 |

宽表需要横向查数、图纸需要辨认标尺、时间轴需要跨期跟踪时，可把中部依据与下部图表合成主体区，并将判断标在相应数据行、图纸部位或节点上。例如产品审议看原稿第 17 页，上方并排原始平面与布置图，下方以室内参考图交代风格。审新稿时应能读清尺寸，分辨实景、参考案例和本项目方案。[原稿第 17 页](visuals/standard-orange-detail-17.png)

需要研究原稿图文比例时可查[原稿几何位置](measured-layout.json)，其数值基于 1280×720 的等效画布。

## 业务配图

排页时先说明读者要看清的细节，例如交付验收由谁陪同、工单在哪个环节积压、两种岗位怎样交接。为重点页确定图片内容、实图线索、需要生成或绘制的部分以及最终占用的版面。读者也可以通过图片认识对象、理解机制或预览变化；涉及实际业绩、具体人员、现场缺陷、合同原文或正式系统状态的判断，要由相应原始记录支持。

页序底稿可用一行记下“本页问题／要不要图、图讲什么／从哪找或按什么生成／摆在哪里、读者应看清什么”。这是排版决定，成品里不打印这行。要讲步骤、对照或方案变化时，图可以直接承担该部分内容，正文只补关键条件。例如：

- 客服页：客户重复来电时怎样转交工单？／要图，展示查单和转派两步／取本次培训系统截图；未经上线的改版用示范界面／相邻两幅局部放大，标注原单号码和转派按钮。
- 培训页：新服务台如何分工接待？／要图，一张中景说明谁核对资料、谁接待等候来宾／没有场地照片时，生成日常社区服务台的拟议办理情景，两人各做一项工作／以大图为主体，两条原生标注分别指向登记台和等候区。
- 债务到期表：每一笔到期额和受限条件是什么？／本页留足空间给逐项表格，装饰照无助核对／金额来自借款台账／按期限分列并保留小计。需要解释资金从何汇入时，可另用资金路径图。

从业务问题选图，下面只列几种常遇到的选材路径。碰到未列出的业务，仍用同一行底稿直接判断。

| 举例：本次要读懂什么 | 有实图时怎样展示，缺图时怎样处理 |
|---|---|
| 财务资金：交付为什么影响收入确认 | 选可用的交付验收现场、交接材料局部或业务系统截图。缺图可生成验房师陪同业主对照交接清单的自然场景。入账时间、金额、回款分别按报表核对。 |
| 工程安全：整改做法怎样落地 | 同部位同角度原图标出隐患与整改点。缺少完工照时，按方案绘出防护位置或生成预期作业场景，保留“拟整改”状态。 |
| 审计法务：授权与用印怎样衔接 | 截取允许使用的审批界面或条款局部，标记操作人和复核点。原件不适用时画职责图，解释交接关系，条款、签章和金额取自真实文件。 |
| 人力培训：新员工如何完成第一次交班 | 实拍台面、单据与操作细节并加注。无原照可生成培训情景，示范交出人与接班人各自的动作，考勤与培训实绩另用记录。 |
| IT 客服：工单分派为何延迟 | 用真实界面截取队列和转派入口。讲述改版可绘有明确标注的界面原型或生成服务台场景；真实耗时及故障先后以日志为准。 |
| 物业经营：报修怎样受理并上门 | 用工单局部、设备实照或人员到场照片标出责任对象。拟议便民服务可生成接待台的办理情景，再用流程图交代派单和回访。 |
| 投资评审：改造标的会改变哪项现金投入 | 用标的现状照片、边界图对照拟改造范围，图上标出影响投入的部位。按测算绘制投入时序；改造后的效果可生成示意，租金与回报另核依据。 |
| 酒店经营：入住高峰为什么排队 | 用大堂现场照片或平面标注客人、行李和前台的动线，配分时抵达量及等候记录。调整方案可生成入住情景，对照看人员及设备将摆在哪里。 |
| 商业、文化旅游及联动经营：演出散场如何衔接商铺和接驳车 | 用场馆出口、营业商铺、接驳点实图配开放时段及步行线路。新线路可绘路线图，拟设服务点可生成人视角示意；实际入店和乘车人数按各自记录。 |

这些例子同样适用于其他条线，选图依据是本次读者的问题。按具体对象查找本次资料及附件、获授权的内部素材库，再考虑与本题准确匹配且可用的公开原图。有合适实图则裁切、放大或标注要看的部分。真图对象、时期或场景对不上时，可另找可用实图，也可就本题生成展示图。现有材料不足以说明真实状态时，给出业务机制或预期效果的示意，不以生成图补作事实凭证。呈现岗位协作、流转或操作界面时，可结合原生流程图、标注图或界面示意，文字与数值保留可编辑。无须让每个数字页再配一张照片。

**生成与实看。** 指定真实岗位、工作对象、动作、器具、环境、光源和所需景别。按最终版心预留裁切空间。人物目光、手势、人与设备比例、文字标识、物体遮挡及行业操作应符合常识；避免过度磨皮、全员对镜头微笑、虚构徽标、乱码与过度戏剧化光效。生成后实际打开查看，有明显摆拍感、物理错误或业务动作错误时调整或重做；文字、标签和精确数值宜用可编辑对象补入。图注说明读者该看什么，标明“业务场景示意（AI生成）”“方案效果示意（AI生成）”或“界面原型”等真实属性。核对最终导出页上的清晰度、裁切和图注指向。

公开发布前确认实图的使用权、适用对象及必要署名；内部截图按使用场合裁掉个人和商业敏感字段。保留资料实图、参考图与生成示意的区别。
