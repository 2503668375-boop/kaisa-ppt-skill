# 视觉参数与中文排版

## 先满足阅读任务，再选择版式

公司日常经营、定价、投资、产品、推售和专项方案采用 [阅读型专项汇报密度](company-report-density.md)。页面容纳回答问题所需的事实、比较、原因和动作，不用大图、大数字和留白掩盖分析不足。

主席版以决策摘要和关键证据形成短主线；内部经营版增加构成、预测和责任；外部版围绕事实、履约与诉求。三者都不能只靠减少正文完成受众适配。

## 原稿继承与公司四层页面（硬约束）

有公司原稿时，从原稿副本制作，保留母版、标识、页眉线、标题位置、字体和正文网格。通用工具的 60px 安全区、32px 大标题、深色卡片、巨型数字、视觉锚点配额不得覆盖越海原稿。公司页型是否合格，先看与原稿同类页的结构是否一致。

标准分析页采用下列顺序；原稿中的大表、时间轴和图纸页优先保证字段、节点与标注清晰，可就地承载分段依据。

| 层级 | 越海参考位置（960×540pt） | 内容要求 |
|---|---|---|
| 左上标题 | x≈23—60，y≈10—20 | 议题或判断，常见约16—18pt，沿原稿，不改造成超大标题 |
| 页首概括 | x≈38—60，y≈45—80 | 一句完整业务概括，使用本稿唯一主强调色，写清结果、建议及必要数字 |
| 分段依据 | y≈80—140，或主体前部 | 两至三条事实、比较或原因；用“销售结果、余货结构、金额口径”等具体标签 |
| 主体证据 | 约y100—510 | 完整表格、竞品参数、图纸、地图或左右对应措施；表格字段服务决策 |
| 页底收束（按需） | 约y484—522 | 只写本页取舍、动作或业务影响，不重复页首概括 |

越海 P4 是“概括＋三条依据＋三组竞品/决策信息”，P7 是“概括＋两条依据＋完整大表＋备注”，P10 是“概括＋完整表格＋两行判断＋结论带”，P12 是“概括＋左右事实与措施＋结论带”。制作时打开对应大图并排检查，不以记住色值代替读页。

禁止将上述结构替换为“左上大标题＋巨大百分比＋深色卡片＋少量文字”。普通分析页必须有足够的分段依据和主体证据；没有证据时补资料或缩小结论，不靠视觉放大填空。

## 画布、品牌与网格

越海原稿画布为 13⅓ × 7.5 英寸、16:9，对应 PDF 960 × 540 pt。其他物理尺寸的原稿按相同显示宽度检查，不机械复制字号。

| 项目 | 参数或做法 |
|---|---|
| 主强调橙 | `#EE7700`，用于品牌识别、局部线条、节点和适当图形 |
| 正文黑灰 | `#000000`、`#212121`、`#595959` |
| 主强调色 | 越海橙版用 `#EE7700`；红色封面版用 `#C00000`，全稿统一 |
| 辅助深蓝 | `#1B2A4E`，少量用于分组、总计或图表系列 |
| 主体底色 | 白色 `#FFFFFF` |
| 辅助底色 | 暖白 `#FAF7F2`、浅暖灰 `#F2EFEB`、浅橙 `#FFF1E4` |
| 分隔线 | `#DDD6CE`、`#C9C9C9`，细线为主 |

橙色越海版保持白底和暖中性色；红色封面版只替换封面与内页强调规则；原汇报橙黄版继承当前指定原稿。品牌标识保持比例和原色，不重画、不打字仿制。

内容页建立统一页眉、左右边距、栏网格、页脚和页码。16:9 页面可从左右 0.4—0.55 英寸、顶部 0.25—0.4 英寸起调；标题与正文之间保留稳定间距。封面只保留题名、版本或日期及必要题签，不机械增加一组“本页主题”。

## 中文字体与字号层级

中文优先使用苹方、微软雅黑、思源黑体等可读无衬线字体；一页纸按 Word 母版的宋体、字号和行距制作。整份 PPT 原则上使用一个中文主字体家族，通过字重建立层级，避免微软雅黑、新宋体和其他字体混杂。

13⅓ × 7.5 英寸阅读型页面可从以下范围起调：

| 层级 | 建议起点 | 用法 |
|---|---|---|
| 封面题名 | 30—40 pt | 完整事项名称，避免过大口号 |
| 内容页标题 | 越海原稿常见16—18 pt；其他阅读型20—24 pt | 判断句或具体对象；公司原稿优先 |
| 导语/关键判断 | 15—18 pt | 关键逻辑，不重复标题 |
| 正文 | 12—14 pt | 完整分析，1.25—1.45 倍行距 |
| 表格 | 10.5—12.5 pt | 依列数与显示宽度调整 |
| 图注/来源 | 9—10 pt | 对象、日期、单位与必要出处 |
| 页码/辅助信息 | 8.5—9.5 pt | 不抢阅读注意 |

投影或远距离汇报应提高正文至约 16—20 pt，并减少单页内容或增加附件。不得靠缩到难以阅读的字号容纳超量内容，也不为追求大字号把一项完整论证拆成提词卡。

字号层级通常不超过四级。字重、位置、间距和线框共同建立层次，不给每个栏目配置一种字色。

## 中文分行、段落与对齐

- 正文左对齐，避免大段两端对齐造成字距拉伸；短标签和数字可居中。
- 宽栏正文每行约 28—42 个汉字作为排版起点；长论证用宽栏，短并列事项用双栏，避免三列细长碎句。
- 行距通常为字号的 1.25—1.45 倍，段间距约 0.4—0.7 个行高；同组内容靠近，不同组用间距分开。
- 避免逗号、句号、顿号、右括号落在行首，避免左括号、书名号前半留在行尾。
- 避免段末只剩一个汉字或一个标点；通过改写、调整框宽和字距修正，不强行加空格。
- 数字与单位不拆行，日期、金额和百分比尽量保持完整；必要处使用不换行空格或调整文本框。
- 同级文本框统一内边距、基线和段距；同类标题底线对齐，图注与对应图片对齐。
- 不以全角空格和连续回车排版，使用真实栏网格、间距和对象对齐。

## 文字颜色与强调

标题、正文、一般数字、图注、单位和图例默认黑色。每份报告只设一种主强调色，不能部分页面橙色、部分页面红色。

- **橙色越海版**：页首概括、重点文字、编号、关键数字和结论带统一使用越海橙 `#EE7700`；正文黑色，深蓝只作少量辅助。
- **红色封面版**：内页需要强调时统一使用红色 `#C00000`，不与橙色混用。
- **原汇报橙黄版**：沿用当前指定原稿的一种强调色，不另增第二种高饱和强调色。

封面、深色表头、实心标签及深色照片上的白色反字应保证对比度。重点内容通过统一强调色、字重和位置体现，不依赖多色区分。

一页通常只有一个主要视觉重心。强调色过多时，先减少强调，不增加更多颜色平衡。

## 表格：服务比较和精确查阅

表格用于货盘、价格、费用、经营目标与实际、产品指标、方案比较和权利义务。不要把长段叙述全部装进单元格，也不要为了“图文丰富”删除必要字段。

- 表头使用浅暖灰或浅橙，黑色文字；减少重网格，以细横线和留白分组。
- 文本列左对齐，数值列右对齐，同一列小数位一致；合计或推荐行可加粗。
- 单位尽量放入列名，如“均价（万元/㎡）”；日期和口径写入表题或表下注释。
- 目标、实际、差额、完成率等字段按决策需要排列，差额与原因靠近。
- 长表按逻辑分段，重复表头并保留总计；不得把大表缩成不可读截图。
- 去除 PowerPoint 默认蓝白主题样式，正文和表格文本可编辑。

## 数据图表：让比较一眼可读

- 图表标题直接写比较对象和结论，坐标、图例和数据标签注明单位与统计期。
- 能直接标注系列时减少往返图例；重点系列使用本稿唯一主强调色，其他系列用灰色。
- 趋势使用折线，构成使用条形或堆积，方案差异使用同字段条形或小表；两项简单算术不必制作大图。
- 坐标范围不得夸大差异；占比写清基数，合计不等于 100% 时检查口径。
- 关键数据页标明统计日期。引用外部数据时可短注机构与日期，内部核验记录留在底稿。
- 图表标签不得重叠；不同软件显示不稳定时，优先使用原生表格或可编辑形状，不悄悄改成不可编辑截图。

## 图片、地图与图纸

图片大小由证明任务决定。标注地图、同尺度户型、剖面和空间对照可以占主体；普通氛围图不得挤掉货盘、价格和经营分析。

真实地图保留必要道路、站点、比例与方向；规划图保留红线、北向、图例和关键指标；户型图保留尺寸与功能名称。裁切不得损失证据。

真实现场图、参考案例和设计意向图分别标注。设计意向图用“设计意向（AI生成）”，不得冒充项目实景或批准方案。

## 常用汇报页型

| 页型 | 信息组织 | 视觉重心 |
|---|---|---|
| 决策摘要 | 核心结果、推荐方案、经营影响、决策项 | 一条主判断＋紧凑决策区，明细进后文 |
| 经营结果 | 目标、实际、差额、构成与原因 | 主表或差额图，旁列关键解释 |
| 方案取舍 | 同字段方案比较、推荐、代价与条件 | 对照表或双方案图，推荐项明确 |
| 市场/竞品 | 同口径事实、差异、项目影响 | 数据图或项目对照，不用无关城市大图 |
| 货盘定价 | 货量、户型、楼层、价格、货值与销售职责 | 分层货盘表＋必要总平标注 |
| 客户与营销 | 客群约束、顾虑、动作、案场承接与转化 | 客户证据和动作对应，不堆身份标签 |
| 产品审议 | 原方案问题、调整对照、参数与经营影响 | 图纸/剖面为主，解释靠近对应位置 |
| 费用立项 | 费用构成、对应资源、交付、销售任务 | 构成图或表＋资源与承接关系 |
| 责任节点 | 任务、责任、完成物、日期、依赖 | 责任表或时间轴，避免只有口号 |
| 外部诉求 | 已履责任、当前事实、计划、请求事项 | 事实与诉求一一对应 |

越海同类页大图见 `visuals/yuehai-01.jpg`、`yuehai-02.jpg` 和 `visuals/full/`。继承其信息关系，不照搬历史业务内容和固定构图。

## 多泳道营销时间轴

月份轴与所有泳道共用一套网格。使用“1 个标签列＋N 个真实月份列”，营销节点、推广、活动、渠道、销售和供货按月份跨度对位；轴线、圆点和箭头可绝对定位叠加。

月份数、列宽和节点来自本次资料。不得目测摆放，不沿用历史样例中的年份、开盘节点和活动名称。PPTX 使用原生形状保持可编辑。

## 页面节奏与留白

相邻页面可在地图、图表、对照、照片和图纸之间自然切换。真正需要同字段比较时可连续使用相同结构；不得为了变化牺牲比较，也不连续多页使用同样三卡片。

留白用于分隔证据组和建立阅读顺序。页面缺关键分析时，先补证据或合并低密页，不用大图、大字号和空泛总结填满。
