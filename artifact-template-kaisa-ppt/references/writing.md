# 佳兆业汇报的文字表达

## 后台工作与汇报内容

公司汇报采用业务负责人向公司汇报的表达，直接陈述经营结果、原因、产品与价格安排、销售及回款节奏、资金需求和执行计划。资料收集、数据验证和生成过程属于 Agent 的后台工作。

- **默认不出现在汇报文件中**：报告口径认定、数据来源说明、原表引用、单元格地址、文件路径、模型校验、公式错误列表、工作表覆盖索引、历史模板修订、事项核定清单、AI 自评，以及“按用户指定文件”“原表保留”“待相关条线核定”等制作视角措辞。不得转移到附录、页脚、隐藏页或演讲者备注；不得用“经营风险”“协同动作”等新标题继续呈现同一制作任务。用户要求“表格内容全部展示”时，应完整承接业务信息，不因此加入上述后台材料。
- **来源与证据仍需后台保存和核对**：图注保留对象、单位、日期、案例名称及“参考案例／示意”等必要辨识；来源网站、机构、文件名、表名和证据链留在私有底稿。只有用户明确要求资料索引、审计或校核报告，或素材确有署名要求时，才在对应交付中保留必要来源或核验说明。
- **业务事实的必要限定仍然准确**：计划、预测、目标、实际应使用准确名称；含税／不含税、统计区间、金额单位等可直接写在字段或表头。真实存在且影响经营的约束，写清影响对象、金额、时间和业务安排；不能把 Agent 未完成的查数、源表差异或公式核验直接当成经营事项。不得虚构已核实、已批准、已到账等状态。
- **无法自主解决的数据问题单独沟通**：先在后台追查并解决；涉及未经授权的数据改动或关键事实仍不明确时，在聊天中集中说明或追问，不擅改原表，不把检查任务塞给汇报受众，也不把不可靠结果写成确定结论。真正需要公司作经营决策的事项，按本次汇报目的具体表达，不自动增加“联合核定事项”章节。

例：现金回款汇报应呈现年度回款、产品贡献、到账节奏和资金安排；“来源：某工作簿第几行”“回款口径待认定”“核验已通过”“请财务复核公式”留在后台或交付聊天中。删除这些说明后，仍需保留准确的金额、期间和计划／实际属性。

## 直接、具体的业务表达

用户明确要求去掉防御性推断及机械句式。这项要求适用于标题、导语、正文、图注、结论和讲稿，不能把同一套措辞换词后保留。

- 成品文案禁用“边界”，直接写其具体业务对象，如用地红线、供货范围、售价、投入金额或产品配置；禁用“先……后……”“先……再……”和“不是……而是……”式套句。实际时间顺序用日期、节点和动作表达。
- 不主动添加“守住底线、设置安全垫、双重门槛、有条件推进、保留退出选择、暂不作承诺”等防御性推断；不为了显得严谨，把整份项目介绍写成限制、提醒和审批流程。
- 未由用户、公司制度或真实业务条件提出的回报阈值、暂停条件、追加审批及退出机制，不得自行设定为建议。仅把这些词换成“原则”“纪律”“条件”也不合格。
- 项目机会写清区位、配套、客户、产品和收益如何形成；方案写明开发什么、服务谁、投入多少、如何销售。结论直接回答本次汇报的问题，不把 Agent 的自我保护写成管理层决策逻辑。
- 客观不利因素保留具体内容：如轨道保护范围、成本增量、按揭放款时间、销售变化。用金额、面积、日期及对应方案陈述，不扩写成泛化风险提示。事实、测算与建议用字段或短图注区分；重大未知单独在聊天中说明，不散布于全稿。不得用确定语气包装未知事实。

### 句式改写（只使用题设事实）

以下数值仅示范表达，不进入其他项目报告。

- “交通价值边界：邻近地铁不等于有效通勤。” → “凤凰城双线换乘，连接光明与南山工作生活圈；人行出入口与站点接驳动线同步设计。”
- “先把资金安排落实，再有条件推进项目。” → 已知节点时写“首期地价6.535亿元，第二期于合同签订起一年内缴清；建设融资覆盖主体施工至交付。”没有融资证据时不写最后分句，缺失信息在聊天中说明。
- “守住收益边界，不为核心地段过度支付溢价。” → “住宅均价3.9万元/㎡情景下，货值26.65亿元、测算余量2.12亿元。”
- “满足双重门槛后参拍，否则保留退出。” → 删除 Agent 自造的门槛和退出安排，按本次实际任务陈述投资建议、具体理由或需要决定的事项。

## 学什么

主样本是越海，辅助学习投资可研的条件表达、经营汇报的量化表达。用户强调“文字丰富、内容详实、专业、没有废话”，所以不能把去空话理解为删掉解释、只留大标题。每段都应让读者获得此前不知道的事实、关系、判断或动作。

专业感来自准确识别问题和交代决策依据。保留地产行业通用术语，如去化、回款、货值、总价门槛、标准层、面宽、动线、层高、分期、成本、供货节奏，但不能把术语堆成形容词。

## 参考中的有效句法

以下引用为历史表达样本，不作为当前项目事实使用。

1. 越海 P7：“小户型低总价快速去化，大面积依靠景观资源控量做溢价。”
   - 明确不同产品的经营职责、价值依据及规模取舍。
   - 可借鉴结构：某类产品承担什么任务，另一类凭什么形成收益，以及怎样控制风险。
2. 越海 P13：关于裙房、双塔和中庭限制平面面积，继而影响限高条件下各业态层高的分析。
   - 写清现有方案 → 空间约束 → 产品影响，随后给实际尺寸。不能简化成“产品品质有待提升”。
3. 越海 P13：“越大户型应占有越大面宽，占有越好景观资源。”
   - 把价值判断落成可供设计实施的资源分配原则。
4. 越海 P14：“规整建筑形态和结构布置，控制办公进深”，并交代上下结构与管井对位。
   - 动作有对象，措施有技术落点。继承这种具体程度，不继承未经核实的用途转换或审批判断。
5. 前海 2020 年度汇报 P4：实际营销费率与年初预算对比，拆迁贷利率由 9.3% 降至 7.5%，并交代节省金额。
   - 经营改善使用基准、变化及结果，避免只说“降本增效取得显著成果”。历史数值不带入新项目。
6. 长沙投资可研 P7：合作方式、出资比例、借款期限、资金偿还顺序和违约返还条件分别列清。
   - 条件复杂时允许完整长句、编号条款和密集表格。把决定权利义务的细节写清比追求短句更重要；只有确需逐项对照的条款才用表格，其余用完整正文与关系示意。

## 适用表达，不做固定套句

| 内容任务 | 应交代的关系 | 写作方式 |
|---|---|---|
| 市场研判 | 哪类供需变化，对项目有什么影响 | 具体市场事实 → 解释其影响 → 项目机会与经营判断 |
| 竞品比较 | 可比条件与真正差异 | 同面积/总价/区位/时点下比较；区分报价、备案、成交 |
| 客户分析 | 谁在什么情境下需要产品 | 通勤/居住/投资约束 → 关注因素 → 产品承接 |
| 定位取舍 | 优先服务谁、兼顾什么、放弃什么 | 对象 → 产品职责 → 收益与风险权衡 |
| 产品建议 | 哪一部分怎么调整、为什么 | 位置/面积/配置/动线/层高 → 具体做法 → 依据与条件 |
| 经营复盘 | 与什么基准相比发生了什么 | 完成情况 → 差距及原因 → 能落地的改进 |
| 营销行动 | 对哪类客户、围绕哪个节点做什么 | 目标客群 → 活动/渠道/动作 → 节点与转化安排 |
| 经营约束 | 已有业务事实会如何影响目标 | 具体约束 → 金额/时间影响 → 业务安排；数据核验任务留在后台 |

并非每段必须装下整条链条。一张表可负责事实，一段正文负责解释，一张图负责空间条件。不要机械地在每页重复“现状—问题—策略—效果”四个栏目。

## 标题、导语、正文、图注分工

- 标题：优先使用“议题｜具体判断”，或清楚的对象名称。12—28 个汉字可作为布局起点，不是硬字数限制。标题判断必须有正文支撑。
- 导语：说明判断的关键逻辑或方案组合，通常 1—2 行。避免把标题扩写一次。
- 正文：写出证据、原因、比较、方案和条件，允许完整段落。段首短标签应帮助查阅，如“总价控制”“动线组织”，不要另起“战略赋能”“价值跃迁”等空标题。
- 图注：注明项目/对象、图示内容、单位、必要时间和参考属性；按上文成品要求把来源追溯留在底稿。不要把正文结论再贴一遍。
- 页底总结条：只有能够归纳取舍或补充行动时使用。标题和导语已说清的，不再固定加总结。

## 删除什么，保留什么

删除或具体化：

- “随着时代发展”“在当前复杂背景下”“具有重要战略意义”等不改变判断的铺垫。
- “全方位赋能”“多维协同”“持续释放价值”“构建发展新格局”等没有对象和机制的抽象表述。
- “我们可以看到”“本页主要说明”“综上所述”“值得注意的是”等可直接去掉的演讲或写作提示。
- “高端、品质、尊贵、标杆、稀缺、顶级”堆叠而没有产品事实。
- 同一事实在标题、导语、模块标题、页底结论中反复出现。
- 为了凑三点、四大策略或固定页数添加的次要事项。

必须保留：

- 改变结论的数据、范围、时点、样本与统计口径。
- 方案取舍的原因，为什么选这一路径、什么条件下成立。
- 影响实施的审批、建筑、财务、客户或运营条件；集中写在相关位置，避免每页复制通用提醒。
- 支撑复杂决策的必要长段落、完整对比表和技术细节。
- 经证据支持的专业术语和适度的地产价值表达。

删掉一句后如果读者仍能获得完全相同的信息，这句话通常可以删。删掉后失去因果、条件或关键参数，则应重写或换版式容纳。

## 改稿示例

以下均为虚构的写作演示，不能作为真实项目结论。改写只使用题设材料，不补造“显著提升”等结果。

### A. 空泛定位 → 有分工的产品策略

原稿：以多维价值赋能为抓手，打造差异化产品矩阵，全方位满足多元客群需求，推动项目高质量发展。

题设：小户型用于控制总价；高区有景观条件；大户型客群窄、销售周期长。

改写：小户型承担主力销售，控制总价门槛；大户型集中高区，利用景观条件形成差异，同时控制供应规模，降低销售周期拉长对回款的影响。

版式：两类产品并列，分别放产品职责、资源依据和控制条件。只有取得真实数据后才补配比或销售周期。

### B. 重复“品质” → 完整的客户解释

原稿：客户重视品质，对品质生活有较高要求。项目应通过高品质产品满足品质客群需求，打造高品质生活标杆。

题设：受访客户在周边就业，关注通勤；两人常住，需要独立会客；对后期物业费用敏感。

改写：核心客户以周边就业、两人常住的家庭为主，购房时优先考虑通勤便利和室内功能。产品宜保留独立会客空间，并控制后期物业使用成本，避免公共配套增加持续支出。

说明：并非越短越好。这段保留了客群、需求、产品动作和费用约束四层信息。

### C. 技术意见 → 约束、影响、处理

原稿：进一步优化平面布局，全面提升产品竞争力与居住舒适度。

题设：大户型面宽偏小；景观面被次要空间占用；户数不能增加。

改写：现有大户型面宽偏小，主要景观面被次要空间占用，客餐厅的采光与视野受到限制。建议在不增加户数的前提下调整功能布局，将主要景观面优先配置给客餐厅，具体尺寸在平面深化时校核。

版式：原始平面图标出问题，旁列两项调整原则；避免另配无关豪宅照片掩盖问题。

### D. 经营口号 → 有依据的结果

原稿：强化成本管控，持续提升经营效能，降本增效取得良好成果。

题设：虚构项目本期营销费率 1.0%，预算 1.3%；暂无费用总额。

改写：本期营销费率 1.0%，较预算低 0.3 个百分点。

说明：不能写“下降 0.3%”，不能凭费率差虚构节省金额。费用总额缺失留在工作底稿，成品不附加“暂不折算”的自我解释。

### E. 营销泛话 → 与节点有关的动作

原稿：整合高端圈层资源，以精准触达推动品牌势能转化，形成营销闭环。

题设：样板房下月开放，已储备有明确面积需求的老客户，活动对象为这批客户。

改写：围绕下月样板房开放，按面积需求梳理已储备客户，分批安排定向邀约和看房。活动后逐组记录对户型、价格及交付的反馈，形成下一轮跟进清单。

说明：未给出的场次、人数、转化率不编造。无需再在页底重复“精准触达、闭环转化”。

## 全稿编辑方法

1. 建一个私有的“页码—问题—判断—新增依据”清单，先检查相邻页是否实际讲同一件事。
2. 对重复部分，选择证据最完整的一页承担论证；其他页转向不同问题，或合并。
3. 逐段圈出具体名词、事实、动作和条件。只剩形容词及抽象名词的段落重写。
4. 检查长短：短到看不出原因就补解释；长但都是必要信息则重组或分页。不要用统一字数上限代替判断。
5. 以图像、数据图表和正文共同组织论证。产品建议缺少画面时生成设计意向效果图；纯文字矩阵不默认转成表格。
6. 最后通读成稿，检查语气是否适合企业正式汇报。样本中的宣传性极值、未经验证的确定判断和个别重复不需要照抄。
7. 通读语气及推断来源：发现禁用句式、泛化警告或自造门槛时重写整段，不能只删关键词。
