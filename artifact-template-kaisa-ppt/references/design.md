# 公司汇报的视觉表达

拿到逐页方案再排版。普通正文页左上放具体议题，标题下用一两句话写判断或安排，中段按本题确有的理由分段，下面放供读者核对的图、表或图纸。先给关键字段、数值标签或尺寸线留够位置，再安排文字。遇到整幅图纸、宽表、时间轴，把依据写到具体部位、数据行或节点旁边。按读者要核对的细节决定是否变换构图。

## 画布、品牌与网格

标准橙色原稿画布为 13⅓ × 7.5 英寸、16:9，对应 PDF 960 × 540 pt。其他物理尺寸的原稿按相同显示宽度检查，不机械复制字号。

| 项目 | 参数或做法 |
|---|---|
| 主强调橙 | `#EE7700`，用于品牌识别、局部线条、节点和适当图形 |
| 正文黑灰 | `#000000`、`#212121`、`#595959` |
| 主强调色 | 标准橙色版用 `#EE7700`；红色封面版用 `#C00000`，全稿统一 |
| 辅助深蓝 | `#1B2A4E`，少量用于分组、总计或图表系列 |
| 主体底色 | 白色 `#FFFFFF` |
| 辅助底色 | 暖白 `#FAF7F2`、浅暖灰 `#F2EFEB`、浅橙 `#FFF1E4` |
| 分隔线 | `#DDD6CE`、`#C9C9C9`，细线为主 |

每份成品使用同一套原稿的画布、封面、内页母版、标识和封底。标准橙色版沿用白底和暖中性色。另两套均继承所选原稿的品牌识别，标识保持比例和原色。

内容页建立统一页眉、左右边距、栏网格、页脚和页码。16:9 页面可从左右 0.4—0.55 英寸、顶部 0.25—0.4 英寸起调，标题与正文之间保留稳定间距。封面原文字框内排本次题名、汇报人和汇报时间，按[固定模板清单](fixed-templates.md)核对。版本号仅在确有版本管理要求时附注。

## 中文字体与字号层级

中文优先使用苹方、微软雅黑、思源黑体等可读无衬线字体；一页纸按 Word 母版的宋体、字号和行距制作。整份 PPT 原则上使用一个中文主字体家族，通过字重建立层级，避免微软雅黑、新宋体和其他字体混杂。

13⅓ × 7.5 英寸阅读型页面可从以下范围起调：

| 层级 | 建议起点 | 用法 |
|---|---|---|
| 封面题名 | 继承所选原稿 | 完整事项名称，署名和日期为副文 |
| 内容页标题 | 标准橙色原稿常见16—18 pt；其他阅读型20—24 pt | 简短业务题名，沿用公司原稿位置 |
| 导语/关键判断 | 15—18 pt | 关键逻辑，不重复标题 |
| 正文 | 12—14 pt | 完整分析，1.25—1.45 倍行距 |
| 表格 | 10.5—12.5 pt | 依列数与显示宽度调整 |
| 图注 | 9—10 pt | 对象、日期、单位和示意属性 |
| 页码/辅助信息 | 8.5—9.5 pt | 不抢阅读注意 |

投影或远距离汇报应提高正文至约 16—20 pt，并减少单页内容或增加附件。不得靠缩到难以阅读的字号容纳超量内容，也不为追求大字号把一项完整论证拆成提词卡。

字号层级通常不超过四级。字重、位置、间距和线框共同建立层次，不给每个栏目配置一种字色。

## 中文分行、段落与对齐

- 正文左对齐，避免大段两端对齐造成字距拉伸；短标签和数字可居中。
- 宽栏正文每行约 28—42 个汉字作为排版起点；长论证用宽栏，短并列事项用双栏，避免三列细长碎句。
- 行距通常为字号的 1.25—1.45 倍，段间距约 0.4—0.7 个行高；同组内容靠近，不同组用间距分开。
- 避免逗号、句号、顿号、右括号落在行首，避免左括号、书名号前半留在行尾。
- 避免段末只剩一个汉字或一个标点；通过改写、调整框宽和字距修正，不强行加空格。
- 数字与单位不拆行，日期、金额和百分比尽量保持完整；必要处使用不换行空格或调整文本框。
- 同级文本框统一内边距、基线和段距；同类标题底线对齐，图注与对应图片对齐。
- 不以全角空格和连续回车排版，使用真实栏网格、间距和对象对齐。

## 文字颜色与强调

标题、正文、一般数字、图注、单位和图例默认黑色。每份报告只设一种主强调色，不能部分页面橙色、部分页面红色。

- **标准橙色版**：页首概括、重点文字、编号、关键数字和结论带统一使用品牌橙 `#EE7700`；正文黑色，深蓝只作少量辅助。
- **红色封面版**：内页需要强调时统一使用红色 `#C00000`，不与橙色混用。
- **原汇报橙黄版**：沿用当前指定原稿的一种强调色，不另增第二种高饱和强调色。

封面、深色表头、实心标签及深色照片上的白色反字应保证对比度。重点内容通过统一强调色、字重和位置体现，不依赖多色区分。

一页通常只有一个主要视觉重心。强调色过多时，先减少强调，不增加更多颜色平衡。

## 表格：服务比较和精确查阅

表格用于货盘、价格、费用、经营目标与实际、产品指标、方案比较和权利义务。不要把长段叙述全部装进单元格，也不要为了“图文丰富”删除必要字段。

- 表头使用浅暖灰或浅橙，黑色文字；减少重网格，以细横线和留白分组。
- 文本列左对齐，数值列右对齐，同一列小数位一致；合计或推荐行可加粗。
- 单位尽量放入列名，如“均价（万元/㎡）”；日期和口径写入表题或表下注释。
- 目标、实际、差额、完成率等字段按决策需要排列，差额与原因靠近。
- 长表按逻辑分段，重复表头并保留总计；不得把大表缩成不可读截图。
- 去除 PowerPoint 默认蓝白主题样式，正文和表格文本可编辑。

## 数据图表：让比较一眼可读

- 图表标题直接写比较对象和结论，坐标、图例和数据标签注明单位与统计期。
- 能直接标注系列时减少往返图例；重点系列使用本稿唯一主强调色，其他系列用灰色。
- 趋势使用折线，构成使用条形或堆积，方案差异使用同字段条形或小表；两项简单算术不必制作大图。
- 坐标范围不得夸大差异；占比写清基数，合计不等于 100% 时检查口径。
- 关键数据页标明统计期间和口径。内部经营稿的来源信息只进底稿；从历史原稿复制图表时，一并清理标题括注和原有来源小字。
- 图表标签不得重叠；不同软件显示不稳定时，优先使用原生表格或可编辑形状，不悄悄改成不可编辑截图。

## 图片、地图与图纸

图片大小由证明任务决定。标注地图、同尺度户型、剖面和空间对照可以占主体；普通氛围图不得挤掉货盘、价格和经营分析。

真实地图保留必要道路、站点、比例与方向；规划图保留红线、北向、图例和关键指标；户型图保留尺寸与功能名称。裁切不得损失证据。

实拍、参考案例和生成图按真实用途注明属性。生成的业务情景可写“业务场景示意（AI生成）”，拟议方案可写“方案效果示意（AI生成）”。各条线按[业务配图](composition-detail.md#业务配图)选取、生成及检查图像。

## 常用汇报页型

| 页型 | 信息组织 | 视觉重心 |
|---|---|---|
| 决策摘要 | 核心结果、推荐方案、经营影响、决策项 | 一条主判断＋紧凑决策区，明细进后文 |
| 经营结果 | 目标、实际、差额、构成与原因 | 主表或差额图，旁列关键解释 |
| 方案取舍 | 同字段方案比较、推荐、代价与条件 | 对照表或双方案图，推荐项明确 |
| 市场/竞品 | 同口径事实、差异、项目影响 | 数据图或项目对照，不用无关城市大图 |
| 值班排班 | 分时业务量、人员覆盖、积压和处理时长 | 时序图＋岗位表 |
| 数字系统 | 可用率、影响范围、恢复过程、复发原因 | 趋势图＋事件时间线 |
| 货盘定价 | 货量、户型、楼层、价格、货值与销售职责 | 分层货盘表＋必要总平标注 |
| 客户与营销 | 客群约束、顾虑、动作、案场承接与转化 | 客户证据和动作对应，不堆身份标签 |
| 产品审议 | 原方案问题、调整对照、参数与经营影响 | 图纸/剖面为主，解释靠近对应位置 |
| 费用立项 | 费用构成、对应资源、交付、销售任务 | 构成图或表＋资源与承接关系 |
| 责任节点 | 任务、责任、完成物、日期、依赖 | 责任表或时间轴，避免只有口号 |
| 外部诉求 | 已履责任、当前事实、计划、请求事项 | 事实与诉求一一对应 |

用所选模板中的同类页面核对标题区、主图和说明的关系。业务文案与构图随实际任务调整。

## 活动排程、媒体排期与财务报表

选版式时先问读者要核对顺序、同期动作，还是金额关系。沿用公司页首、品牌和字体，主体可用整页时间轴、横向排期表或财务主表。时间节点、横条、文字和金额尽量使用可编辑对象。[单日流程轴与媒体排期示例](../assets/event-and-media-schedule.pptx)在同一张可编辑页上展示活动时点和发布矩阵。两者有同一批节点时可同页对照，仅需其中一项时保留相应组件，按本次安排替换字段。多项工作跨阶段联动时，改用下文的营销节点总排期。

| 情境 | 主体如何排 | 成稿应当看清什么 |
|---|---|---|
| 单场活动、分批接待 | 几个节点用横向流程轴；时段较多或说明较长用纵向时间轴或“时段／环节／内容”表。不同批次分轨，地点图贴近对应环节。 | 谁在何时、何地参加哪一批，哪些环节有先后，哪些可并行。日历日期待定时只写一次，现有资料仅定了两个批次就标“第一批／第二批”。只有原案给出钟点、时长时才标数。 |
| 多媒体、多阶段推广 | 用“渠道或媒介 × 周次或阶段”排期矩阵。每格放当期发布的具体物料或交付；跨期工作用横条，单点发布用标记。各行共用一套时间网格。 | 哪个渠道在什么阶段交付哪项内容。日期、批次和责任按已确认安排填写；只确定发布两次时用批次表达，不能自行编出发布日期。 |
| 财务报表、预算与经营差异 | 用科目为行，同口径期间、预算与实际或不同场次为列。数值右对齐，单位进表头，小计、合计与分项分层；只需解释增减来源且数据能勾稽时，可配桥接图。 | 支出或收入归属哪一项、总额如何组成、差额来自哪里。预算表不添未发生的实绩或人为分摊。 |

时间跨度有实际意义时按比例绘制，如跨月营销排期按真实月份对位。仅有阶段次序时等距列节点，不把序号当日期。借鉴流程图的节点与短注释、甘特图的共用日历网格、财务桥接图的期初与期末勾稽；实际应用按本题内容取舍。

## 跨期营销节点总排期

适用于一场营销战役跨越多个真实阶段，管理层要在同页核对节点、传播、活动和拓客如何配合。采用[可编辑营销节点总排期示例](../assets/marketing-schedule-overview.pptx)的主体结构，在本次公司母版中填写已确定的任务。单场内的接待顺序用活动轴，单条媒体发布用发布清单，多媒体排期用渠道矩阵，收入、支出与预算用财务主表。

- **设置统一横轴。** 上沿按实际月份排布，用圆点定位关键节点、箭头指示推进方向。日期未定而先后已定，可改用正式阶段名。所有泳道严格共用列边界。跨期工作从实际开始列铺到结束列，单点工作落在对应节点。
- **依工作内容分行。** 左侧四行分别为营销节点、推广计划、活动计划、客户拓展。营销节点写推售或开放事项。推广计划按阶段填写传播主题、交付物与渠道。多个阶段确实共用的一条传播主线或固定渠道，用跨列说明带写一次。活动按实际时段列名称、参与对象及动作。拓客按客源、邀约方式与当期任务对应填写。只有本案确有的工作才落格。
- **按列核验协作关系。** 选一个关键节点，沿同一列向下读，应看得出当期发什么、办什么、联系谁。回看已定日程与原案，核对节点、跨列区间、内容所属行及名称。工作线过多时另页展开明细。参考图中的旧日期、项目、品牌、置业场景及宣传语均不转入新稿。

## 页面节奏与留白

相邻页面按读者的任务选图表、图纸或同字段对照。需要跨页比较相同指标时维持相同顺序与尺度。讨论的问题已经变化时重新组织主体区。

留白用于分隔证据组。看缩略图时找出连续几页相同的三栏、大片空框和重复构图，再按实际尺寸核对每栏是否交代了不同事项。只有一句判断和装饰图的页，优先并到有对照数据或安排的相关页。文字过密时先删复述、重组表格，再按读者问题拆页。有关密度与标签可读性的实图见[正反例对照](company-report-density.md)。
