# 模板与资料索引

| 原生材料 | 使用场合 |
|---|---|
| [标准橙色 PPT](../assets/reference.pptx) | 默认公司标准汇报，从原稿副本继承品牌和内页秩序 |
| [橙黄色 PPT](../assets/reference-yellow-report.pptx) | 需要相应原稿的封面、横线和标题处理时使用 |
| [红色封面 PPT](../assets/reference-red-cover.pptx) | 用户指定红色封面或相应公司模板时使用 |
| [通用 Word 一页纸](../assets/one-page-report.docx) | 单独传阅的说明、通报、复盘、申请或决策摘要 |

原生演示文稿及历史参考图仅供识别版式。它们的标题、对象、旧数字和业务方案都须在工作副本中替换。技能不依赖特定磁盘、项目文件夹或历史客户材料。模板文件校验值见[模板清单](source-fingerprints.json)。
