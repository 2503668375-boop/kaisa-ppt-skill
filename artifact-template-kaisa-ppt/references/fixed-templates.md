# 固定模板清单

## PPT 成套使用

| 选定模板 | 封面 | 封底 |
|---|---|---|
| [标准橙色](../assets/reference.pptx)（默认） | 原第1页，整幅橙底、右上标识、居中题名与日期 | 最后一页保留原橙底资产，中文短句“汇报完毕　敬请指示” |
| [橙黄色](../assets/reference-yellow-report.pptx) | 原第1页的封面构图、题名框与品牌元素 | 原最后一页，橙黄色“感谢聆听” |
| [红色封面](../assets/reference-red-cover.pptx) | 原第1页的红色底图、标识和题名 | 原最后一页，红色“感谢聆听” |

从选定原稿的副本制作。标准橙色封面保留居中题名、固定图形和原文字框左上位置及宽度。日期行沿用模板下移后的段前间距。日期取实际会议或约定的呈报日期，沿用原稿精度或用户指定格式。标题使用本次正式事项名称，版本标记随实际需要填写。另两套继承各自原稿的题名与品牌布局，按用户指定字段填写。

用户明确要求封面署名时，用实际汇报人或单位。在原题名框内把题名、署名、日期分段，署名与日期成组。标准橙色日期单行沿用模板约52磅的段前距。署名版把署名和日期作为副文组，署名前约56—62磅起排，组内日期紧接下一行。若用户有指定视觉位置，以最终页面为准。原框采用垂直居中时，增加副文或段前距应配合向下加高原框，保留题名视觉位置。用成品实际位置核对，副文组放在封面下半部，题名与副文组应明显留白，副文两行保持紧凑。可从前后两版的文字上沿及主副文之间的实际距离复核。最后一张业务页后接同套中文封底。正式汇报收尾可用四、六、八字短句。标准橙色默认使用模板内两组四字句。沿用旧原稿时，把旧英文收尾替换成中文短句，保持原文字框与品牌图形。

## 首尾页核对

在技能目录运行[核对脚本](../scripts/check_bookends.py)，标准橙色默认用题名和日期：

```bash
python3 scripts/check_bookends.py "assets/reference.pptx" "成品.pptx" \
  --title "东区周六接待排班试行申请" --date "2026.11" --closing "汇报完毕　敬请指示"
```

本次明确要求封面署名时，再加 `--presenter "客户服务部"`。如果已按用户批注明确向下扩展原题名框，再加 `--allow-cover-title-grow`。只传两份文件时，核对画布、首尾固定资产和模板收尾文案。旧标准橙色原稿也按中文短句验收。原框文字核对适用于上述题名与日期布局及其署名版。另两套原稿有不同字段布局时按实际模板目视核对相应字段。

打开最后一次导出的首尾页。读出本次题名、日期和要求显示的署名，检查可见位置、字色、断行及主副文距离。封面题名位置应稳定，副文组不得贴近标题。读出最终封底的中文文字。配有 Word 时，核对两份材料的报告身份及时间。内页另按[页面构图](composition-detail.md)复核。

## Word 一页纸

使用[紧凑 Word 母版](../assets/one-page-report.docx)的副本。A4 竖向、单栏、白底黑字，上下约 2.30 厘米，左右约 2.10 厘米。题名含日期、署名均居中，宋体四号加粗，署名段后留 4—6 磅，随后接一级标题或正文。一级标题为宋体小四加粗，分项及正文为宋体小四常规，默认固定 18 磅行距。需要编号时沿用自动编号。按议题决定章节，按[一页纸规则](one-page.md)校对层级、紧凑度及末行，确保一张 A4。
